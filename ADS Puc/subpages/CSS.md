# Formato

```css
seletor {
	propriedade1: valor;
	propriedade2: valor
}
```

## Tipos de seletores

- # → usados para id. (obs, o id é único em toda a página)
- . → usados para classes
- * todos os elementos

## Formas de instanciar:

- Inline: <p style="color: blue">Meu texto</p>
- Incorporado: Dentro do cabeçalho, entre as tags <style> e </style>
- Importado: Feito em um arquivo separado, importado dentro do html
```html
<-- Arquivo index.html -->
<link href="estilo.
css" rel="stylesheet">
```
