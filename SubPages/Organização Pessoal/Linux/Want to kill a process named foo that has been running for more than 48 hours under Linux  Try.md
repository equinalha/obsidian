Want to kill a process named foo that has been running for more than 48 hours under Linux ? Try
killall -o 24h foo

Here is how to force kill a process that has been running for less than 30 minutes:
killall -y 30 -9 appName

See [**cyberciti.biz/faq/how-force-…**](https://www.cyberciti.biz/faq/how-force-kill-process-linux/) for more info.
