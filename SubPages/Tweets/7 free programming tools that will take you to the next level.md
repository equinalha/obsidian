1. Scribe

Writing up docs and how-to guides used to take up so much time, but not anymore!

[**@ScribeHow**](https://www.twitter.com/ScribeHow) creates auto-generated step-by-step guides, cutting down hours of work to minutes.

It's a must-have tool if you're working solo or in a team.

👉 [**getscribe.how/chrome**](http://getscribe.how/chrome)

2. Tab Suspender

As devs, we sometimes have a lot of tabs open, and it chews up precious memory & CPU. 

What’s the solution? Suspend the tabs you aren't using. 

This extension catches inactive tabs freeing up to 80% memory and device resources.

👉 [**tab-suspender.com**](http://tab-suspender.com/)
> [https://pbs.twimg.com/media/Fj_-uIWWAAc_dih.jpg](https://pbs.twimg.com/media/Fj_-uIWWAAc_dih.jpg)

> [!note] 📌
> **Chris Staudinger **[***@ChrisStaud:***](https://www.twitter.com/ChrisStaud)
3. ColorZilla

If you use other sites for design inspiration then this is the extension for you.

Their eyedropper tells you the code for any color on a webpage.

"Must have" tool for frontend devs or designers.

👉 [**colorzilla.com**](http://colorzilla.com/)
