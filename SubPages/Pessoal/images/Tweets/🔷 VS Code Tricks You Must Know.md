✅ Multiple Cursors

👉 To add cursors at arbitrary positions, select a position with your mouse and use ALT + CLICK.

> [!note] 📌
> **Mrunay Uttarwar **[***@MrunayU:***](https://www.twitter.com/MrunayU)
✅ Move Line up & Down

👉 To move a whole line up & down, put the cursor on that line and use ALT + UP OR ALT + DOWN.

> [!note] 📌
> **Mrunay Uttarwar **[***@MrunayU:***](https://www.twitter.com/MrunayU)
✅ Copy Line up & Down

👉 To copy a whole line up or down, put the cursor on that line and use SHIFT + ALT + UP OR SHIFT + ALT + DOWN.

> [!note] 📌
> **Mrunay Uttarwar **[***@MrunayU:***](https://www.twitter.com/MrunayU)
✅ Rename A Symbol

👉 To Rename a symbol, select the symbol then press F2.

👉 Write a new name and hit enter.

👉 All occurrences will be updated.

> [!note] 📌
> **Mrunay Uttarwar **[***@MrunayU:***](https://www.twitter.com/MrunayU)
✅ Code Formatting

👉 To Format the currently selected source code use CTRL + K CTRL + F & for the whole document use Shift + Alt + F.
