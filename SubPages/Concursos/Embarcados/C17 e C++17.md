# C/C++

- frequentemente chamada de linguagem de médio nível
-  combina elementos de linguagens de alto nível com a funcionalidade da linguagem assembly
- Apesar de ser uma extensão do C, o C++ não é totalmente compatível com a linguagem C.
	- Por exemplo, o C++ introduziu uma nova palavra-chave para a alocação de memória (new), enquanto o C usava a função malloc()
- C é uma linguagem de programação case sensitive

## Modificadores

- `const`
- `volatile`
	- Indica ao compilador que o valor de uma variável pode ser alterado de forma não especificada no programa
	- Utilizado para otimizações realizadas pelo próprio compilador
- `static`
	- Quando aplicado a variáveis locais, dentro de uma função, retém o valor destas entre diferentes chamadas da mesma função
	- Quando aplicado a variáveis globais, faz com que estas estejam acessíveis somente dentro do arquivo em quem foram declaradas
- `register`
	- Indica ao compilador que o valor da variável declarada como register seja armazenado em um registrador da CPU ao invés da memória principal
	- Para cálculos que necessitam de grande velocidade
	- **Foi removido do C++17**
- `virtual`
	- é usado para implementar o conceito de **polimorfismo** em programação orientada a objetos
	- permite que você declare funções que podem ser substituídas em classes derivadas
	- permite que a função chamada seja determinada em **tempo de execução**,
	- A existência de ao menos um método declarado como `virtual` em uma classe a torna uma classe abstrata e por consequência ela **não poderá ser instanciada diretamente**.
	- Um método é dito puramente virtual quando é declarado da seguinte forma: 
```c++
virtual void func_1() = 0;
```
-  `protected`
	- Membros declarados como `protected` são acessíveis apenas dentro da própria classe e por classes que a herdam (subclasses).
- `private`
- `public`
- Padrão:
	- Para classes: `private`
	- Para structs: `public`

# LibO2

[https://github.com/greyshell/libO2/tree/main](https://github.com/greyshell/libO2/tree/main)

- Biblioteca escrita em **C** que fornece uma coleção de **estruturas de dados comuns** e **funções utilitárias** projetadas para facilitar o desenvolvimento de aplicações eficientes e robustas
- Permite o uso de estrutura de dados em C (não precisa C++)
- **Estruturas de Dados Comuns**:
	- **Pilhas (Stacks)**: Implementações de pilhas usando listas simplesmente encadeadas.
	- **Filas (Queues)**: Estruturas de filas para gerenciamento de dados em ordem FIFO.
	- **Listas Ligadas (Linked Lists)**: Implementações de listas ligadas para inserções e deleções eficientes.
	- **Tabelas Hash (Hash Tables)**: Estruturas de tabelas hash para acesso rápido a dados.
	- **binary_heap_dynamic_array_int**
- Algoritmos
	- bubble sort
	- cocktail sort
	- counting sort
	- quick sort
- Inclui uma suíte de testes abrangente para garantir a confiabilidade e a robustez das estruturas de dados e funções fornecidas.

## Exemplo de uso

```c
/*
 * Autor: greyshell
 * Descrição: Exemplo de uso da pilha da LibO2
 */

#include <stdio.h>
#include "stack_singly_linkedlist_int.h"

int main(void) {
    int out_data = 0;
    bool return_type;
    stack s;

    // Inicializa a pilha
    initialize_stack(&s);

    // Verifica se a pilha está vazia
    return_type = is_empty_stack(&s);
    printf("A pilha está vazia: %d \n", return_type);

    // Empilha um elemento
    return_type = push(&s, 7);
    if (return_type){
        printf("Elemento empilhado com sucesso \n");
    }
    else {
        printf("Falha ao empilhar \n");
    }

    // Consulta o elemento do topo da pilha
    return_type = peek(&s, &out_data);
    if (return_type){
        printf("Elemento no topo da pilha: %d \n", out_data);
    }
    else {
        printf("Falha ao consultar o topo da pilha \n");
    }

    // Exibe os elementos da pilha
    printf("Elementos na pilha: \n");
    display_stack(&s);
    printf("\n");

    // Desempilha um elemento
    return_type = pop(&s, &out_data);
    if (return_type){
        printf("Elemento desempilhado: %d \n", out_data);
    }
    else {
        printf("Falha ao desempilhar \n");
    }

    // Obtém o tamanho da pilha
    int stack_size = get_stack_size(&s);
    printf("Tamanho da pilha: %d \n", stack_size);

    // Deleta a pilha
    return_type = delete_stack(&s);
    printf("Pilha deletada com sucesso: %d \n", return_type);

    return 0;
}
```

## String

```c++
// Inclua a biblioteca de string
#include <string>
// Crie uma variável de string
string saudacao = "Olá";
// Saída do valor da string
cout << saudacao;
```

- Concatenação:
	- feito usando o operador de adição (+) ou o método `append()`.
	- A diferença é que a operação + cria strings temporárias para a concatenação
	- Já o método `append()` modifica a string **in loco**, sendo portanto mais eficiente
	- Não é possível concatenar strings com outros tipos
		- Para adicionar um número a uma string, é necessário converter o número em uma string primeiro, usando uma função de conversão, como to_string() ou stringstream.
- Tamanho
	- para obter o comprimento de uma string, você pode usar a função` length()` ou` size()`
- Aspas:
	- Para strings (vários caracteres) utiliza-se aspas duplas
	- Para caracteres `char` utiliza-se aspas simples

# Características do C++17

- Definições de namespace aninhadas, por exemplo:
```c++
namespace X::Y 
{ … }

// ao invés de
namespace X 
{ 
	namespace Y { 
		...
	} 	
}
```
- Atributos para namespaces e modificadores:
	- `[[fallthrough]]`
		- usado em **instruções **`**switch**` para indicar que a execução deve continuar para o próximo `case` sem um `break`. 
		- Isso ajuda a evitar warnings do compilador quando o comportamento é intencional e pode melhorar a legibilidade.
```c
#include <iostream>

void testFallthrough(int n) {
    switch (n) {
        case 1:
            std::cout << "Case 1\n";
            [[fallthrough]];  // Intencionalmente cair para o próximo case
        case 2:
            std::cout << "Case 2\n";
            break;
        default:
            std::cout << "Default case\n";
    }
}

int main() {
    testFallthrough(1);  // Vai imprimir "Case 1" e "Case 2"
}
```
	- `[[maybe_unused]]` 
		- utilizado para indicar que uma variável ou função **pode não ser utilizada** em algum contexto, prevenindo warnings do compilador sobre variáveis não usadas.
```c
#include <iostream>

void testMaybeUnused([[maybe_unused]] int x) {
    // x não é utilizado, mas o compilador não emitirá um aviso
}

int main() {
    int y = 10;
    testMaybeUnused(y);  // Chama a função sem utilizar x
    return 0;
}
```
	- `[[nodiscard]]` 
		- indica que o valor de retorno de uma função **não deve ser ignorado**. 
		- Se a função for chamada e **seu retorno não for usado**, o compilador gerará um warning
```c
#include <iostream>

[[nodiscard]] int calculateSum(int a, int b) {
    return a + b;
}

int main() {
    calculateSum(3, 4);  // Aviso do compilador: valor de retorno ignorado
    return 0;
}
```

## Principais mudanças

- `std::any`
	- Introduz a tipagem dinâmica ao C++
	- Permite armazenar valores de qualquer tipo
- `std::optional`
	- Permite representar objetos opcionais
	- Para casos em que um algoritmo pode não retornar um valor
- `std::variant`
	- Permite armazenar **um de vários tipos possíveis** em um único objeto.
	- Diferente de um `union`, o `std::variant` rastreia qual tipo está atualmente armazenado, permitindo um gerenciamento seguro de múltiplos tipos. 
	- Se você tentar acessar o tipo errado, uma exceção será lançada ou uma chamada segura falhará.
	- `std::get`
		- Usado para acessar o valor armazenado de um tipo específico. 
		- Se o tipo armazenado não for o mesmo tipo solicitado, uma exceção `std::bad_variant_access` será lançada.
	- `**std::holds_alternative**`:
		- Permite verificar se o `std::variant` atualmente contém um valor de um tipo específico.
```c++
#include <variant>
#include <iostream>
#include <string>

int main() {
    // Declarando um std::variant que pode conter int, float ou std::string
    std::variant<int, float, std::string> var;

    // Armazenando um int
    var = 10;
    std::cout << std::get<int>(var) << std::endl;  // Acessando o valor como int

    // Mudando o tipo armazenado para string
    var = "Hello, World!";
    std::cout << std::get<std::string>(var) << std::endl;  // Acessando o valor como string

    // Tentando acessar o valor com o tipo errado causa uma exceção
    try {
        std::cout << std::get<int>(var) << std::endl;  // Tentativa de acesso incorreto
    } catch (const std::bad_variant_access& e) {
        std::cout << "Erro: " << e.what() << std::endl;
    }

    return 0;
}
```
- `std::string_view`
- **Estruturas de bindings:**
- variáveis `inline`
	### O problema com variáveis globais antes de C++17
	Se você tivesse uma variável global ou estática em um arquivo de cabeçalho incluído em vários arquivos `.cpp`, ocorria um erro de **linkagem múltipla** (multiple definition error), pois a variável seria definida em cada arquivo de tradução. O C++ evitava isso utilizando a palavra-chave `extern` para indicar que uma variável seria definida em um único arquivo `.cpp`, e os outros arquivos só teriam declarações dessa variável.
	### Exemplo antes de C++17:
```c++
// header.h
extern int globalVar;  // Declaração (não definição)

// source.cpp
int globalVar = 42;    // Definição
```
    Nesse caso, o arquivo de cabeçalho só contém a declaração, enquanto a definição real da variável (`globalVar = 42`) é colocada em apenas um arquivo fonte.
    ### O que muda com `inline` em C++17?
    Com C++17, as variáveis podem ser marcadas como `inline`. Isso significa que você pode definir variáveis globais em arquivos de cabeçalho, e o compilador garantirá que apenas **uma instância** dessa variável exista no programa, mesmo que o cabeçalho seja incluído em múltiplos arquivos de tradução.
    ### Exemplo com `inline`:
```c++
// header.h
inline int globalVar = 42;  // Definição de uma variável inline
```
    Nesse caso, mesmo que o arquivo `header.h` seja incluído em múltiplos arquivos de código-fonte, o compilador tratará a variável `globalVar` como uma única definição em todo o programa, evitando o problema de redefinição múltipla.
- **fold expressions**
```c++
auto sum(Args... args) {
	return (... + args);  // Fold expression
}
```
- `**if constexpr**` 
	- permite ao compilador avaliar uma condição em **tempo de compilação**. 
	- Diferente do `if` tradicional, que é avaliado em **tempo de execução**, o `if constexpr` elimina o código não utilizado durante a compilação, o que pode otimizar significativamente o programa, especialmente em cenários de **metaprogramação**.

# Standard Template Library

- conjunto de modelos no C++, usados para prover estruturas mais complexas de dados e funções, como **listas, pilhas, arrays**, entre outros
- é uma biblioteca de classes contêineres, algoritmos e iteradores

![[SubPages/Concursos/images/image 9.png]]

- **contêineres**
	- estruturas de dados
	- são implementados como templates de classe
	- `vector`, `list`, `deque`, `set` e `map`. 
- **algoritmos**
	- funções genéricas que realizam operações nessas estruturas de dados, como `sort`, `find` e` for_each. `
- **iteradores**
	- são objetos que permitem a navegação pelos elementos de um container do C++.
- **functors**
	- objetos de função
	- são objetos que podem ser usados como argumentos de funções,
- **adaptadores**
	- são componentes que modificam o comportamento de outros componentes do STL.
	- Por exemplo, o `reverse_iterator `consegue inverter a ordem dos elementos em um contêiner

## Contêineres

### Sequenciais

- `**Array**`
	- Tamanho fixo
- `**Vector**`
	- Tamanho dinâmico
- `**dequeue**`
	- Lista encadeada
	- Permite inserção tanto no fim quanto no início
- `**forward_list**`
	- Lista encadeada unidirecional
	- Cada elemento aponta para o próximo
- `**list**`
	- Lista duplamente encadeada
	- Cada elemento aponta tanto para o próximo quanto para o anterior

### Associativos

- `**set**`
	- Armazena elementos únicos em **ordem crescente**
	- Usa uma árvore binária balanceada
	- Ideal para buscas rápidas de elementos únicos
- `**map**`
	- Chave - valor
	- **Caves únicas e ordenadas**
- `**multiset**`
	- Permite elementos duplicados
- `**multimap**`
	- Permite chaves duplicadas

### Associativos desordenados

- `**unordered_set**`
- `**unordered_map**`
- `**unordered_multiset**`
- `**unordered_multimap**`

### Adaptadores de contêineres

- `**stack**`
- `**queue**`
- `**priority_queue**`

## Iteradores

- Similar a um ponteiro que aponta para um elemento específico dentro de um contêiner
- Utilizado para se mover através dos elementos do contêiner

![[SubPages/Concursos/images/image 10.png]]

- **Tipos**
	- Random-Access
	- Bidirectional
	- Forward
	- Output
	- Input
- quando um contêiner suporta o iterador bidirectional, por exemplo, ele suporta todos os iteradores “abaixo” dele.

![[SubPages/Concursos/images/image 11.png]]

- Estrutura - Iteradores:
	- **Random-Access**
		- `vector`, `deque`, `array`, `string`
	- **Bidirectional**
		- `list`, `set`, `multiset`, `map`, `multimap`
	- **Forward**
		- `forward_list`, `unordered_set`, `unordered_multiset`, `unordered_map`, `unordered_multimap`

### Input

- Permite ler elementos em um contêiner, de forma sequencial, do início ao fim, uma única vez
- Operações:
	- Acessar `it`
	- Leitura de elementos` *it`
	- Incremento de posição` ++it`
	- Comparação de igualdade` it == it2`, ou desigualdade `it != it2`.

### Output

- Enquanto o input apenas lê os elementos do contêiner, o **output é capaz de escrever elementos dentro do contêiner**
- De forma sequencial, do início ao fim, uma única vez
- Operações:
	- Escrita de elementos `*it = valor`
	- Incremento de posição `++it`

### Forward

- permite ler e escrever elementos em um contêiner
- de forma sequencial, com múltiplas passagem permitidos - mas apenas em um fluxo unidirecional, do início ao fim
- É a forma utilizada para iteradores de buscas lineares.
- Operações:
	- Acessar `->`
	- Leitura de elementos` *it`
	- Escrita de elementos` *it = valor`
	- Incremento de posição `++it`
	- Comparação de igualdade `it == it2`, ou desigualdade `it != it2`

### Bidirecional

- Permite ler e escrever múltiplos elementos em um contêiner
- de forma sequencial, em ambas as direções
- Múltiplas passagens permitidas
-  frequentemente usado para buscas reversas
- Operações
	- Leitura de elementos` *it`
	- Escrita de elementos `*it = valor`
	- Incremento de posição `++it`
	- Decremento de posição` --it`
	- Comparação de igualdade` it == it2`, ou desigualdade it `!= it2`

### Random-Access

- Permite leitura e escrita de elementos tanto em forma sequencial, quanto em forma direta
- Acesso a qualquer elemento em tempo constante
- Operações:
	- Acessar` ->` e `[index]` (posição direta)
	- Leitura de elementos` *it`
	- Escrita de elementos `*it = valor`
	- Operações completas de iteração, como incremento `++it`, decremento `--it`, atribuição `+=it`, e outros.
	- Operações completas de comparação, como igualdade `==`, diferença `!=`, maior que `>`, menor que `<`, e outros.
