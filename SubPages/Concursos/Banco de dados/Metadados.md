# Tipos de metadados

- **Descritivos**
	- Informações básicas sobre os dados
	- Título, autor, data de criação, formato de arquivo
- **Estruturais**
	- Organização e estrutura dos dados
	- Campos, tabelas, relacionamento entre dados
- **Administrativos**
	- Gestão e controle dos dados
	- Acesso, segurança, versão, histórico de alterações
- **Técnicos**
	- Informações técnicas sobre os dados
	- Resolução, tamanho do arquivo, formato de compressão, software utilizado para criar ou processar os dados
- **De preservação**
	- Informações necessárias para preservação dos dados
	- Migração, preservação de formatos, autenticidade, integridade
- **De direitos autorais**
	- Direitos autorais e licenças de uso
- **De proveniência**
	- História dos dados
	- Como foram coletados, quem criou, quem modificou
