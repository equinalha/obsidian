1. O Apache Kafka é uma plataforma de streaming distribuída que é eficaz para processar dados de eventos de streaming.
2. Ele permite a publicação (produção) e subscrição (consumo) de eventos em tópicos.
3. **Kafka, por natureza, armazena os eventos de forma durável**, o que significa que os eventos são retidos por um determinado período ou até que um limite de tamanho seja atingido.
4. **A plataforma Kafka é frequentemente usada para processar fluxos de eventos em tempo real, mas isso não significa que não haja armazenamento durável.** Pelo contrário, a durabilidade dos dados é uma característica fundamental do Kafka.
5. Kafka pode ser usado para processar dados com ou sem um início ou fim distintos, sendo flexível para diversos cenários.
