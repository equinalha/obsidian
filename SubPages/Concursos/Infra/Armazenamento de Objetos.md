# Características

- tecnologia que permite armazenar e gerenciar dados em formato não estruturado, conhecidos como objetos
- objetos contêm **não apenas os dados**, mas também **metadados** descritivos e um **identificador** único
- Um objeto consiste em **dados binários ou texto**, juntamente com metadados que descrevem esses dados. 
- Os metadados podem incluir informações como data de criação, tipo de arquivo, permissões de acesso, entre outros.
- é ideal para ***data lakes***, pois oferece uma arquitetura adequada para grandes volumes de dados onde cada parte dos dados é armazenada como objeto
- é altamente **escalável** e amplamente utilizado em soluções de nuvem devido à sua capacidade de lidar com grandes volumes de dados de forma eficiente.
- o armazenamento de objetos é **plano e não hierárquico**, o que significa que** não possui uma estrutura de pasta** tradicional encontrada em sistemas de arquivos hierárquicos

## Bucket

- Um *bucket* é um contêiner para objetos em sistemas de armazenamento de objetos
