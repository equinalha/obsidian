# XFS

- Registro de 64 bits
- Suportado pela maioria das distribuições Linux
- Portado para o kernel do linux
- Eficiente na execução de operações paralelas de E/S
- Alocação por meio de árvores B+
- Suporta desfragmentação online
- Suporta:
	- 16 EB de tamanho total do FS
	- Até 8EB de tamanho máximo de um arquivo individual
