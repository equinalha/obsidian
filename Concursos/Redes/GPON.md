# Características

GPON = Gigabit Passive Optical Network

- Capacidade de até 2,5 / 1,25 Gbps (downstream / upstream)
- Rede de ponto a multiponto
- Rede passiva (100% ótica sem equipamento alimentado eletricamente)
- até 100km sem necessidade de amplificadores
- Conceitos:
	- OLT - Optical Line Terminal
	- ONU - Optical Network Unit
	- EPON - Ethernet PON
		- Pacotes de 1518 bytes
		- Uma OLT conecta até 64 ONUs
		- Até 1,25 Gbps
	- GPON
		- Multisserviços
		- Pacotes de 53 até 1518 bytes
