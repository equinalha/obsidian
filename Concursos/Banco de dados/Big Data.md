# Definição

- Big Data pode ser entendido como a **captura, gerenciamento e análise de dados** que vão **além de dados estruturados**
- Difere de Business Intelligence na ordem de grandeza do volume de dados (que é muito maior), e na natureza dos dados.
- Viabilizado hoje devido ao aumento de poder computacional, capacidade de armazenamento e velocidade de transmissão das redes, aliado à redução de custos destes recursos
- **3 V´s → ****5 V´s → ****V´s adicionais**
> [!note] 🔥
> **Vo Vê, Vale Variar com a Vera**

	- **Volume**
	- **Velocidade**
		- Quão rápido os dados estão sendo produzidos e o quão rápido os dados devem ser tratados para atender as demandas
		- Reagir rápido o suficiente para lidar com a velocidade é um desafio para a maioria das organizações.
	- **Variedade**
		- Tipos e formatos diferentes
		- Estruturados, semiestruturados e não estruturados
	- **Veracidade**
		- Considera a falta de confiabilidade inerente em algumas fontes de dados.
		- Por exemplo, medir os sentimentos dos clientes em mídias sociais é incerto por natureza
		- Necessidade de lidar com dados imprecisos
		- Perda de vigência dos dados
	- **Valor**
		- Dados recebidos na forma original, geralmente tem um valor baixo em relação ao seu volume.
		- Um valor elevado pode ser obtido pela análise de grandes volumes destes mesmos dados.
	- **Visibilidade**
	- **Variabilidade**
	- **Visualização**

# Classificações de Big Data

## Metodologia de Processamento

- Análise Preditiva
- Analítico
- Consultas e relatórios
- Outros

## Tipo de conteúdo

- Estruturado
	- Bancos de dados relacionais
- Semiestruturado
	- Textos
	- Postagens de redes sociais
- Não estruturado
	- Áudio, vídeo e imagens

## Fonte de dados

- Web e mídias sociais
- Gerados por máquina
- Gerados por seres humanos
- Internas
- Transações
- Biométricas
