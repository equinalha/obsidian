# Engenharia de Software vs Engenharia de sistemas

<aside>  
🔥 **Sistema envolve software, hardware, pessoas e processos**  
Software é uma parte do sistema

</aside>

- Engenharia de software diz respeito ao desenvolvimento de software, passando por todas as fases, desde a concepção até a operação
- Engenharia de sistemas é um conceito mais amplo, do qual a engenharia de software é uma parte

# Histórico

- Década de 60 - Crise de software
    - Desenvolvimento sem controle
    - Difícil manutenção
- Década de 70
    - Programação estruturada
    - Projeto estruturado
        - Módulos
        - Organização de código
- Década de 80
    - Análise estruturada
        - DFD
        - Dicionario de dados
        - Diagrama ER
        - Diagrama de estados
    - Ferramentas CASE
- Década de 90
    - Análise e projeto OO
    - Java, UML, Processo Unificado
- Anos 2000
    - Metodologias Ágeis
    - Novos paradigmas
        - SOA
        - Aspectos
        - Model Driven
    - Cloud Computing

# Definições

- Software: Programa de computador **e documentação associada**
- Processo: Série conectada de ações
    - Define quem faz o quê
- Processo de software
    - Processo para desenvolver software
