# Introdução

- Computer-Aided Software Engineering
- Ferramentas que auxiliam em atividades de engenharia de software
	- Desde análise de requisitos, modelagem, até programação e testes

# Classificação

## Front End ou Upper CASE

- Apoa as etapas iniciais
- Planejamento, análise e projeto

## Back End ou Lower CASE

- Dão apoio à parte física
- Codificação, testes e manutenção
- Aqui encontram-se as IDE’s

## I-CASE ou Integrated CASE

- Abordam todo o ciclo de vida do software
- Desde requisitos até controle final da qualidade

# Ferramentas de Prototipação

- são utilizadas na fase de design do software para criar modelos rápidos e funcionais do sistema
- permitem aos desenvolvedores e stakeholders visualizarem o produto final e fazerem alterações antes do desenvolvimento completo

# Ferramentas de Teste

- apoiam a validação e a verificação do software
- automatizam os processos de execução de testes
