# O que é

- Security Content Automation Protocol
- conjunto de padrões desenvolvidos pelo NIST para automatizar a avaliação de segurança de sistemas
- SCAP combina várias especificações técnicas, incluindo
	- **CVE (Common Vulnerabilities and Exposures)**: Um banco de dados de vulnerabilidades conhecidas, cada uma com um identificador único.
	- **CWE (Common Weakness Enumeration)**: Classificação das falhas de segurança nos softwares.
	- **CPE (Common Platform Enumeration)**: Um dicionário de produtos de TI, permitindo identificar o software ou hardware vulnerável.
	- **CVSS (Common Vulnerability Scoring System)**: Um sistema de pontuação que classifica a gravidade de vulnerabilidades, permitindo priorização de respostas.
	- **XCCDF (eXtensible Configuration Checklist Description Format)**: Usado para criar checklists de configuração de segurança.
	- **OVAL (Open Vulnerability and Assessment Language)**: Uma linguagem que define como descrever vulnerabilidades e verificações de conformidade.
- Essas especificações são usadas por ferramentas de segurança para ajudar a identificar, avaliar e corrigir vulnerabilidades automaticamente, o que é especialmente importante em ambientes corporativos e governamentais com muitos sistemas de TI.
