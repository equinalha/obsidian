# Bancada Sketcher

![[SubPages/Pessoal/images/image 45.png]]

- Permite a criação de esboços para posterior transformação em sólidos
- O botão abaixo transforma a figura de modo de geometria para modo de referência (não aparecerá no desenho final)

![[SubPages/Pessoal/images/image 46.png]]

- Carbon Copy
	- Ao criar um novo esboço (sketch) no mesmo plano, desenhos de outros sketches estarão visíveis, mas não serão utilizáveis.
	- É possível criar uma cópia dos esboços de outros sketches no atual, para utilizá-los como referência. Para isso, utiliza-se o botão “Carbon Copy¨
![[SubPages/Pessoal/images/image 47.png]]
- Restrições
	- Clicando no botão abaixo, a restrição automática alterna entre somente leitura (referência) para uma restrição ativa
![[SubPages/Pessoal/images/image 48.png]]
	- Redundância de restrições
		- Quando o desenho fica na cor laranja, significa que há mais de uma restrição comandando a medida de uma restrição
![[SubPages/Pessoal/images/image 49.png]]
